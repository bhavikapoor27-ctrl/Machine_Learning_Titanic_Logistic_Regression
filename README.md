# 🚢 Titanic Survival Prediction

## About the Project
A Machine Learning project that predicts whether a passenger survived the Titanic disaster based on features such as age, gender, passenger class, and ticket fare.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Concepts Applied
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Missing Value Handling
- Feature Engineering
- Label Encoding
- Logistic Regression / Classification
- Model Evaluation

## Dataset
Titanic passenger dataset containing demographic and travel-related information.

## Objective
To understand and implement fundamental Machine Learning concepts by building a classification model for survival prediction.
